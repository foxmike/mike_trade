# h

## Goal

Implement the shared deterministic market-context layer. Build multi-timeframe intraday candle aggregation with explicit open/high/low/close/volume, start/end, source provenance, and closed/final status; never expose a developing candle to a strategy that declares completed bars only. Implement pure reusable session VWAP, RSI, EMA, ATR, and volume calculations with deterministic warmup behavior and no provider/network I/O. Implement a U.S. exchange session calendar with America/New_York DST, holidays, regular-hours boundaries, early closes, and session identifiers. Host weekday/time alone is insufficient. Entry cutoffs must be evaluated against effective session close, including half-days. Reference symbols are allowed only as declared strategy inputs, not as a separate market-alert subsystem. Build immutable MarketContext snapshots keyed by as-of/version and carrying quote/trade/candle/indicator data, feed identity, freshness, session status, and optional research context. Enforce warmup/data-quality gates so stale, missing, gapped, zero-volume where relevant, invalid, mixed-feed, or unclosed inputs cannot produce a BUY. Never mix split-adjusted historical prices with raw stop prices. Tests must cover candle boundaries, session reset VWAP, exact indicator edges, early closes/DST, deterministic warmup, and stale/fresh context selection. Materialize exactly the five distinct task_hints for this phase; do not merge hints or create extra implementation tasks. Each generated task must have a nonempty implementation description, exact concrete allowed_write_paths drawn only from expected_changed_files, task-specific measurable acceptance_criteria, focused verification_commands, explicit dependencies matching async_notes, and a reasonable task_timeout_seconds. Use allowed_symbols, forbidden_changes, and a bounded decision budget where they reduce ambiguity. Verification-only work must create a real test or audit artifact. Use targeted verification only during this phase; no broad full-suite runs, large backtests, live orders, or paid data acquisition as incidental checks. This PLAN_SKELETON.json is the complete materialization contract for the phase: do not require, request, or consult any external requirements document to understand scope.
